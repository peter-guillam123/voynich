# Voynich

An interactive explainer on the Voynich manuscript (Yale Beinecke MS 408),
prompted by the Guardian's 6 October 2026 report on the Layfield and
Davis "singulion" paper.

Audience: readers (general public), on phones as much as desktops
Voice: my voice, editorial register, Orwell's six rules
Design: its own look (warm vellum and ink; no Guardian fonts or colours)

## Rules for this project

- Accuracy first. Every factual claim carries a numbered citation that
  links to a source in the sources list. If a thing cannot be sourced,
  it does not go in.
- Say what is established, what is argued, and what is guessed, and keep
  the three apart.
- Images of folios are public domain (Yale Beinecke). `img/manifest.json`
  records where each one came from.
- Vanilla HTML, CSS and JS. No build step. Open `index.html` to run it.
- Works by keyboard and screen reader, respects reduced motion, works on
  a phone.
- `about.html` carries the About page and the build diary.
